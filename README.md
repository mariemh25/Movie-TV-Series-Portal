##  Movie & TV Series Portal

### Overview

The **Movie & TV Series Portal** is a dynamic, multi-page web application designed to help users explore, compare, and manage their favorite movies and TV shows. Built using **HTML**, **CSS**, and **JavaScript**, this project demonstrates front-end development skills through real-world UI/UX features like search, login/register, admin actions, watchlists, and forums.

###  Key Features

*  **Search & Compare**: Search for movies or shows and compare them side-by-side.
*  **Watchlist Management**: Add or remove titles from a personal watchlist.
*  **Login & Register System**: Simulated authentication interfaces.
*  **Admin Actions**: Perform management tasks with a dedicated admin panel.
*  **Theme Toggle**: Light/Dark mode toggle for user preference.
*  **Forum & Contact Pages**: Engage with community and feedback forms.
*  **Back to Top Button**: Improves navigation on long pages.
